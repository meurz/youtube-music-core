Version 0.8.0 adds official-browser Proof of Origin tokens, native Web SABR audio delivery and a licensed official-player route for protected content. All catalog, account and playback protocol requests remain WEB_REMIX.

- The optional provider runs Google's current challenge/VM in a signed-in official Music page. PLAYER and GVS tokens use their respective official bindings. Tokens are scoped to the selected signing session, video and purpose, bounded by expiry, kept in memory and excluded from logs. The CLI supports `--attestation-browser-port`; the Windows helper can generate and install tokens in a dedicated WebView2. Browser generation is an explicit optional dependency, not a native BotGuard emulator.
- Native Rust SABR supports strict UMP/protobuf parsing, bounded complete audio segments, initialization verification, same-container format selection, seek, proof renewal and bounded official playback-context reload. Persistent JSON/C ABI calls expose open/read/seek/close; Rust returns media bytes and JSON uses base64. `ytmusic sabr VIDEO --output FILE` performs a complete transfer without overwriting existing files.
- Encrypted audio is excluded from clear stream/DASH/SABR candidates. DRM descriptors and structured errors route hosts to the official player. A compilable Windows WebView2 helper supports actual CDM probing, official-page playback/seek/pause, protected-session import and attestation. The official page owns EME/CDM/license acquisition; the core does not extract keys or implement a software CDM.
- Protocol 1.2 adds delivery operations while retaining ABI 2 compatibility. Six native release targets remain available, including Windows x64 and ARM64. CI builds both WinUI's WinRT and managed WebView2 projections.

Validation includes a real official-browser PO → native PLAYER/GVS → CDN HTTP206 round trip, native AAC/Opus SABR complete transfers and mid-track seeks, and complete-media decoding. The tested PO track was already playable without mandatory proof. The official Music page passed actual Windows playback/seek/pause; a separate public authorized Widevine vector passed license responses, usable keys, real playback-clock progression, seek and complete encrypted playback to natural end. No known DRM-protected YouTube track was supplied, so YouTube encrypted-track license access is not claimed as live-verified.

Native SABR yields original media segments; progressive playback needs a host demuxer. Full-file MediaPlayer verification is distinct from a progressive adapter. A compatible browser CDM does not remove account, purchase/subscription, region or device-license restrictions. Revoked sessions still require official login/import. Live SABR and native DRM decryption are not provided. Ordinary direct playback remains available without a browser when permitted by the service.

Archives contain the CLI, native library, C header, documentation, .NET examples and third-party notices. Verify SHA256SUMS before installing. Linux requires compatible glibc (2.39 or newer); Windows/macOS binaries are unsigned.
